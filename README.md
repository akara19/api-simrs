Keterangan struktur folder
1. Config --> digunakan untuk mengatur setting konsksi database
2. db --> berisi file .sql yang merupakan file dari seluruh struktur datbase
3. helpers --> berisi file yang digunakan untuk menangkap response dari data json
4. images --> Beriisi kumpulan screenshot cara menjalankan aplikasinya
5. poli --> berisi file-file terkait dengan kebutuhan pada tabel poli yaitu untuk proses CRUD
